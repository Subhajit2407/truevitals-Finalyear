# TrueVitals landing page

## Scope
Build one polished, responsive long-form frontend landing page for TrueVitals. No authentication, backend, APIs, real medical analysis, booking, video, or extra pages.

## Implementation
- Define a premium healthcare design system with off-white surfaces, deep navy type, restrained cyan/blue accents, soft borders, shadows, glass effects, rounded controls, and responsive typography.
- Add the TrueVitals logo, sticky desktop/mobile navigation, and the full requested page flow: hero, four benefits, healthcare exploration carousel structure, three-step process, statistics, mobile app promotion, testimonials, final call-to-action, and footer.
- Split the page into the requested reusable React components while keeping all controls presentation-only.
- Use the uploaded hospital imagery in the visual areas and create named, replaceable placeholder components for future medical-data and phone assets.
- Add lightweight reveal, hover, image-scale, and navigation transitions with reduced-motion support.
- Ensure iPhone-safe spacing, no horizontal overflow, touch-friendly controls, stacked/mobile grids, and horizontally scrollable carousel content.
- Add page-specific title, description, Open Graph, and Twitter metadata.

## Validation
- Check the generated page at desktop and iPhone-sized viewports.
- Confirm responsive navigation, card grids, horizontal carousel behavior, placeholder visibility, metadata, and absence of runtime/build errors.
